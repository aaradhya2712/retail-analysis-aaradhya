Retail Sales Analysis

## Project Overview

This project cleans and analyzes Superstore sales data to find sales trends, profitable products, and profit-margin differences.

## Dataset

The project uses `superstore_sample.csv`. After cleaning, the dataset contains 1,985 rows.

## Tools

- Python with Pandas and Matplotlib
- MySQL for SQL analysis
- Power BI for the dashboard

## How to Run

1. Open `Task1.ipynb` in Google Colab.
2. Upload `superstore_sample.csv` when prompted.
3. Run the notebook from top to bottom.
4. Upload `superstore_cleaned.csv` at the second upload prompt.

## Key Findings

- December 2025 had the highest monthly sales, at about $98,962.
- Copiers Product 12 had the highest total profit, at about $32,700.
- Furniture had a negative profit margin of 4.36%; the East had the lowest regional margin at 6.56%.
